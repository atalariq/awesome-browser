## Browsers

### Mainstream Open Source

- [Firefox](https://www.mozilla.org/firefox/) - Mozilla's open-source browser with strong privacy defaults and extension support.
  `Open Source` `Gecko` `Linux/macOS/Windows/Android/iOS` `Privacy`

- [Chromium](https://www.chromium.org/Home/) - The open-source browser project behind Chrome, maintained by Google.
  `Open Source` `Chromium` `Linux/macOS/Windows/Android` `Developer`

### Privacy-Focused

- [Brave](https://brave.com/) - Chromium-based browser with built-in ad blocking, fingerprinting protection, and Tor integration.
  `Open Source` `Chromium` `Linux/macOS/Windows/Android/iOS` `Privacy`

- [DuckDuckGo Privacy Browser](https://duckduckgo.com/app) - Browser with built-in tracker blocking and privacy controls for desktop and mobile platforms.
  `Open Source` `WebKit/Chromium` `macOS/Windows/Android/iOS` `Privacy`

- [LibreWolf](https://librewolf.net/) - Independent fork of Firefox focused on privacy, security, and freedom.
  `Open Source` `Gecko` `Linux/macOS/Windows` `Privacy`

- [Mullvad Browser](https://mullvad.net/browser) - Privacy-focused browser developed in partnership with the Tor Project, without Tor network dependency.
  `Open Source` `Gecko` `Linux/macOS/Windows` `Privacy`

- [Tor Browser](https://www.torproject.org/download/) - Firefox-based browser configured to route traffic through the Tor anonymity network.
  `Open Source` `Gecko` `Linux/macOS/Windows/Android` `Privacy`

### Chromium-Based

- [Vivaldi](https://vivaldi.com/) - Chromium-based browser with built-in tab management, workspaces, mail, and extensive interface customization.
  `Proprietary` `Chromium` `Linux/macOS/Windows/Android/iOS` `Productivity`

- [Cromite](https://github.com/uazo/cromite) - Chromium fork with enhanced ad blocking, privacy features, and security hardening.
  `Open Source` `Chromium` `Android/Windows/Linux` `Privacy`

- [Ungoogled Chromium](https://github.com/ungoogled-software/ungoogled-chromium) - Chromium variant that removes Google integration and enhances privacy.
  `Open Source` `Chromium` `Linux/macOS/Windows` `Privacy`

### Firefox/Gecko-Based

- [Firefox Developer Edition](https://www.mozilla.org/firefox/developer/) - Pre-release Firefox channel with developer tools and experimental features enabled.
  `Open Source` `Gecko` `Linux/macOS/Windows` `Developer`

- [Floorp](https://floorp.app/) - Firefox derivative focused on privacy, customization, and the open web.
  `Open Source` `Gecko` `Linux/macOS/Windows` `Productivity`

- [Waterfox](https://www.waterfox.com/) - Open-source Firefox fork with privacy-focused defaults and power-user customization.
  `Open Source` `Gecko` `Windows/macOS/Linux/Android` `Privacy`

- [Zen Browser](https://zen-browser.app/) - Firefox-based browser with workspaces, compact mode, split view, and a strong productivity focus.
  `Open Source` `Gecko` `macOS/Windows/Linux` `Productivity`

### WebKit-Based

- [GNOME Web (Epiphany)](https://apps.gnome.org/Epiphany/) - GNOME desktop's WebKit-based browser with minimal design and tracker blocking.
  `Open Source` `WebKit` `Linux` `Minimal`

### Keyboard/Vim-Like

- [qutebrowser](https://www.qutebrowser.org/) - Keyboard-driven browser with Vim-like keybindings and a minimal GUI.
  `Open Source` `QtWebEngine` `Linux/macOS/Windows` `Keyboard`

- [Nyxt](https://nyxt.atlas.engineer/) - Common Lisp browser with programmable commands, keybindings, and engine abstraction.
  `Open Source` `WebKit` `Linux/macOS` `Keyboard`

- [Vimb](https://fanglingsu.github.io/vimb/) - Lightweight Vim-like browser focused on keyboard navigation and speed.
  `Open Source` `WebKit` `Linux` `Keyboard`

- [Luakit](https://luakit.github.io/) - Highly configurable browser with Vim-like bindings and Lua scripting.
  `Open Source` `WebKit` `Linux` `Keyboard`

- [Vieb](https://vieb.dev/) - Vim-inspired browser with a minimal interface and extensive keyboard controls.
  `Open Source` `Chromium` `Linux/macOS/Windows` `Keyboard`

- [Yalqen](https://github.com/YSamed/yalqen) - Keyboard-first Chromium browser for macOS with vertical tabs, a command bar, and built-in ad blocking.
  `Open Source` `Chromium` `macOS` `Keyboard` `Developer`

### Minimal & Experimental

- [Ladybird](https://ladybird.org/) - Independent browser engine and browser built from scratch, emphasizing web standards and security.
  `Open Source` `Ladybird` `Linux/macOS` `Developer`

- [Dillo](https://dillo-browser.github.io/) - Small graphical browser with its own rendering engine for Unix-like systems.
  `Open Source` `Linux` `Minimal`

### Mobile

- [Firefox for Android](https://www.mozilla.org/firefox/browsers/mobile/android/) - GeckoView-based Android browser with tracking protection and support for selected Firefox extensions.
  `Open Source` `Gecko` `Android` `Privacy` `Mobile`

### Terminal & TUI

- [Lynx](https://lynx.invisible-island.net/) - Text-based browser for terminal environments, widely used and actively maintained since 1992.
  `Open Source` `Text-Based` `Linux/macOS/Windows` `Terminal`

- [Links](http://links.twibright.com/) - Text and graphical browser capable of running in terminal or with image display.
  `Open Source` `Text-Based` `Linux/macOS/Windows` `Terminal`

- [Browsh](https://www.brow.sh/) - Text-based browser that renders modern web pages through a headless Firefox backend.
  `Open Source` `Gecko` `Linux/macOS/Windows` `Terminal`

## Browser Engines

- [Blink (Chromium)](https://www.chromium.org/blink/) - Rendering engine used by Chromium, Chrome, Edge, Opera, and many others. Forked from WebKit.
  `Open Source` `Chromium` `Cross-platform` `Developer`

- [Gecko](https://developer.mozilla.org/en-US/docs/Glossary/Gecko) - Mozilla's rendering engine powering Firefox and Thunderbird.
  `Open Source` `Gecko` `Cross-platform` `Developer`

- [WebKit](https://webkit.org/) - Rendering engine used by Safari and many embedded browsers. Originally forked by KDE as KHTML.
  `Open Source` `WebKit` `Cross-platform` `Developer`

- [Servo](https://servo.org/) - Experimental Rust web engine hosted by Linux Foundation Europe and developed for embedding across desktop and mobile targets.
  `Open Source` `Servo` `Cross-platform` `Developer`

- [QtWebEngine](https://doc.qt.io/qt-6/qtwebengine-overview.html) - Qt framework integration of Chromium's rendering engine, used by several niche browsers.
  `Open Source` `Chromium` `Cross-platform` `Developer`

## Browser Extensions

### Privacy & Security

- [uBlock Origin](https://addons.mozilla.org/firefox/addon/ublock-origin/) - Wide-spectrum content blocker with dynamic filtering and filter-list support; full functionality is available on Firefox.
  `Open Source` `Web` `Privacy`

- [NoScript](https://noscript.net/) - Allows JavaScript and other executable content to run only from trusted domains.
  `Open Source` `Web` `Privacy`

- [Privacy Badger](https://privacybadger.org/) - EFF extension that blocks third-party tracking behavior using shipped tracker data and optional local learning.
  `Open Source` `Web` `Privacy`

- [ClearURLs](https://docs.clearurls.xyz/) - Removes tracking parameters and redirects from URLs before your browser follows them.
  `Open Source` `Web` `Privacy`

- [LocalCDN](https://www.localcdn.org/) - Serves popular web frameworks and libraries locally, improving privacy and page load speed.
  `Open Source` `Web` `Privacy`

- [Bitwarden](https://bitwarden.com/download/) - Password manager extension with encrypted vault, cross-device sync, and autofill.
  `Open Source` `Web` `Productivity`

### Developer Tools

- [Wappalyzer](https://www.wappalyzer.com/) - Identifies technologies used on websites including frameworks, CMS, analytics, and libraries.
  `Freemium` `Web` `Developer`

- [React Developer Tools](https://react.dev/learn/react-developer-tools) - Official React debugging extension allowing inspection of component trees and state.
  `Open Source` `Web` `Developer`

- [Vue Devtools](https://devtools.vuejs.org/) - Official Vue.js debugging extension for inspecting component hierarchies and application state.
  `Open Source` `Web` `Developer`

### Reading & Research

- [Zotero Connector](https://www.zotero.org/download/connectors) - Saves citations and bibliography entries to Zotero from web pages with automatic metadata extraction.
  `Open Source` `Web` `Research`

- [Hypothesis](https://web.hypothes.is/) - Open-source web annotation service with a Chromium extension, bookmarklet, and publisher integrations.
  `Open Source` `Web` `Research`

- [SingleFile](https://github.com/gildas-lormeau/SingleFile) - Saves a complete web page including images, fonts, and styles into a single HTML file.
  `Open Source` `Web` `Reading`

### Productivity

- [Raindrop](https://raindrop.io/) - Bookmark manager with tag organization, full-text search, and cross-device sync.
  `Freemium` `Web` `Productivity`

- [OneTab](https://www.one-tab.com/) - Converts all open tabs into a single list that can be restored individually or in groups to save memory.
  `Proprietary` `Web` `Productivity`

### UI Customization

- [Stylus](https://github.com/openstyles/stylus) - User style manager that lets you apply custom CSS themes to websites.
  `Open Source` `Web` `Minimal`

- [Dark Reader](https://darkreader.org/) - Generates dark color schemes for websites in real time, reducing eye strain.
  `Open Source` `Web` `Minimal`

- [Vimium](https://vimium.github.io/) - Provides Vim-style keyboard shortcuts for navigating and controlling the browser.
  `Open Source` `Web` `Keyboard`

- [Tridactyl](https://github.com/tridactyl/tridactyl) - Vim-like keybindings for Firefox with extensive configurability and command system.
  `Open Source` `Web` `Keyboard`

## Developer Tools

### Cross-Browser Testing

- [BrowserStack](https://www.browserstack.com/) - Cloud platform for testing websites and mobile apps across thousands of real devices and browsers.
  `Paid` `Web` `Developer`

- [LambdaTest](https://www.lambdatest.com/) - Cloud-based cross-browser testing platform with automated and live testing on real browsers.
  `Freemium` `Web` `Developer`

### Responsive Design

- [Polypane](https://polypane.app/) - Standalone browser designed for responsive web development with multi-viewport previews and accessibility panels.
  `Paid` `Chromium` `Linux/macOS/Windows` `Developer`

- [Responsively](https://responsively.app/) - Open-source tool that shows a web page simultaneously across multiple device viewports.
  `Open Source` `Chromium` `Linux/macOS/Windows` `Developer`

### Accessibility

- [axe DevTools](https://www.deque.com/axe/devtools/) - Accessibility testing toolkit that identifies WCAG violations within browser DevTools.
  `Freemium` `Web` `Accessibility`

- [WAVE](https://wave.webaim.org/extension/) - Browser extension that overlays accessibility errors, alerts, structure, and contrast information on the current page.
  `Free` `Web` `Accessibility`

### Performance

- [Lighthouse](https://developer.chrome.com/docs/lighthouse/) - Automated tool for auditing page quality across performance, accessibility, SEO, and best practices.
  `Open Source` `Chromium` `Web` `Developer`

- [WebPageTest](https://www.webpagetest.org/) - Hosted browser-performance testing service with configurable locations, connection profiles, filmstrips, and network traces.
  `Freemium` `Web` `Developer`

### Debugging

- [Chrome DevTools](https://developer.chrome.com/docs/devtools/) - Browser-embedded suite of web authoring and debugging tools for Chromium-based browsers.
  `Open Source` `Chromium` `Cross-platform` `Developer`

## Automation & Testing

- [Playwright](https://playwright.dev/) - Cross-browser automation library by Microsoft with built-in auto-waiting and network interception.
  `Open Source` `Headless` `Linux/macOS/Windows` `Automation`

- [Puppeteer](https://pptr.dev/) - JavaScript and TypeScript library for automating Chrome and Firefox through CDP and WebDriver BiDi.
  `Open Source` `Headless` `Linux/macOS/Windows` `Automation`

- [Selenium](https://www.selenium.dev/) - Browser automation framework supporting multiple languages and browsers via the WebDriver protocol.
  `Open Source` `Headless` `Cross-platform` `Automation`

- [Cypress](https://www.cypress.io/) - Open-source browser test runner for end-to-end and component tests, with an optional hosted recording service.
  `Open Source` `Headless` `Linux/macOS/Windows` `Automation`

## Unmaintained, Archived & Historical

- [Bromite](https://www.bromite.org/) - Chromium-based Android browser with ad blocking and privacy enhancements. Unmaintained as of 2024.
  `Archived` `Chromium` `Android` `Privacy` `Archived`

- [Mull](https://gitlab.com/divested-mobile/mull-fenix) - Archived Firefox-based Android browser with privacy hardening and telemetry removal.
  `Archived` `Gecko` `Android` `Archive`

- [w3m](https://github.com/tats/w3m) - Archived terminal browser and pager that remains useful in older systems but is no longer an actively maintained general recommendation.
  `Archived` `Text-Based` `Archive`

- [NCSA Mosaic](https://www.ncsa.illinois.edu/research/project-highlights/ncsa-mosaic/) - Early graphical web browser (1993-1997) that popularized the World Wide Web.
  `Archived` `Proprietary` `Historical` `Archived`

- [Opera (Presto era)](https://help.opera.com/en/operas-archived-history/) - Opera desktop releases through version 12, before the browser moved from the proprietary Presto engine to Chromium in 2013.
  `Archived` `Proprietary` `Historical` `Archived`
